# MindFlow 开发计划

本计划围绕“Codex 分析需求 → 生成思维导图 → 用户手动编辑”的主流程制定。

## 总体进度

- [x] 阶段 0：数据模型基础
- [x] 阶段 1：P0 关系表达
- [x] 阶段 2：P1 富文本样式
- [x] 阶段 3：P1 节点样式
- [x] 阶段 4：P1 全局主题
- [x] 阶段 5：P2 多画布
- [ ] 阶段 6：统一验收与回归

## 阶段 0：数据模型基础

- [x] 文档支持关系、概要、外框、富文本、节点样式和全局主题字段
- [x] 旧版文档自动迁移，现有导图和历史版本保持可读
- [x] 导入导出、提案协议和服务端校验支持新增字段

## 阶段 1：P0 关系表达

- [x] 创建、编辑、删除节点关系线
- [x] 关系线支持文字、颜色、线型和箭头
- [x] 添加概要和外框，支持连续同级节点范围及重新选择范围
- [x] 关系线、概要和外框纳入撤销、重做、历史版本和持久化
- [x] SVG/PNG/JSON 导出包含关系线、概要和外框

### P0 交互优化

- [x] Ctrl/Command 点击节点进行多选
- [x] 多选两个以上节点时，高亮外框和概要快捷按钮
- [x] 顶部工具栏提供外框、概要和连接线快捷按钮
- [x] 概要标题支持双击就地编辑

## 阶段 2：P1 富文本样式

- [x] 支持粗体、斜体、删除线、下划线、字号和文字颜色
- [x] 支持节点内换行及文本对齐
- [x] AI 修改和导出过程保留或合理降级富文本

## 阶段 3：P1 节点样式

- [x] 支持节点形状、填充、边框、圆角和尺寸
- [x] 支持节点文字整体样式和连接线样式
- [x] 布局根据节点尺寸重新计算，避免重叠
- [x] 支持恢复默认样式

## 阶段 4：P1 全局主题

- [x] 支持背景、字体、配色和分支线策略
- [x] 提供内置主题预设
- [x] 支持彩虹分支和主题级默认节点样式
- [x] 明确节点单独样式覆盖全局主题

## 阶段 5：P2 多画布

- [x] 工作区支持新建、切换、重命名、复制和删除画布
- [x] 每张画布独立保存和维护历史版本
- [x] Codex 默认操作当前活动画布
- [x] 支持导出当前画布或整个工作区

## 阶段 6：统一验收与回归

- [ ] 完成自动化测试和生产构建
- [ ] 完成人工编辑、刷新、导入导出和历史恢复回归
- [ ] 完成 Codex 提案预览、应用和冲突保护回归
